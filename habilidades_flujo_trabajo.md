# Habilidades de Flujo de Trabajo

Este documento lista las habilidades de la categoría "Workflow" con una breve descripción de su función en español.

| Habilidad | Descripción |
| --- | --- |
| `agent-orchestration-improve-agent` | Mejora sistemática de agentes existentes mediante análisis de rendimiento, ingeniería de prompts e iteración continua. |
| `agent-orchestration-multi-agent-optimize` | Optimiza sistemas multi-agente con perfilado coordinado y distribución de carga de trabajo. |
| `billing-automation` | Construye sistemas de facturación automatizados para pagos recurrentes, facturación y suscripciones. |
| `changelog-automation` | Automatiza la generación de changelogs (registros de cambios) desde commits y PRs siguiendo formato estándar. |
| `conductor-manage` | Gestiona el ciclo de vida de pistas (tracks) en Conductor: archivar, restaurar, eliminar, renombrar, limpiar. |
| `conductor-new-track` | Crea una nueva pista (track) con especificación y plan de implementación por fases. |
| `conductor-status` | Muestra el estado del proyecto, pistas activas y siguientes acciones en Conductor. |
| `conductor-validator` | Valida artefactos del proyecto Conductor para completitud, consistencia y corrección. |
| `email-sequence` | Crea u optimiza secuencias de email, campañas de goteo (drip) y flujos automatizados de email. |
| `full-stack-orchestration-full-stack-feature` | Orquestación de desarrollo de características full-stack. |
| `git-pushing` | Etapa (stage), comitea (commit) y empuja (push) cambios git con mensajes convencionales. |
| `kaizen` | Guía para mejora continua, prueba de errores y estandarización de código y procesos. |
| `mermaid-expert` | Crea diagramas Mermaid para flujos, secuencias, ERD y arquitecturas. |
| `pdf` | Toolkit completo de manipulación de PDF (extraer texto, crear, unir, dividir). |
| `pdf-official` | Versión oficial del toolkit de manipulación de PDF. |
| `team-collaboration-issue` | Experto en resolución de problemas (issues) de GitHub y flujos de trabajo colaborativos. |
| `track-management` | Gestión de "tracks" de Conductor (unidades lógicas de trabajo para características, bugs, refactorización). |
