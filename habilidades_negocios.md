# Habilidades de Negocios

Este documento lista las habilidades de la categoría "Business" con una breve descripción de su función en español.

| Habilidad | Descripción |
| --- | --- |
| `ad-creative` | Genera, itera y escala creatividades publicitarias: titulares, descripciones, texto principal y variaciones completas de anuncios para cualquier plataforma de publicidad pagada. |
| `ai-seo` | Optimiza contenido para motores de búsqueda con IA, para que sea citado por LLMs y aparezca en respuestas generadas por IA (Google AI Overviews, ChatGPT, Perplexity, etc.). |
| `churn-prevention` | Reduce el abandono de clientes implementando flujos de cancelación, ofertas de retención, recuperación de pagos fallidos (dunning) y estrategias de retención. |
| `competitive-landscape` | Analiza el panorama competitivo, identifica diferenciadores y evalúa el posicionamiento de mercado cuando el usuario lo solicita. |
| `conductor-setup` | Inicializa un proyecto con artefactos de Conductor (definición de producto, stack tecnológico, flujo de trabajo, guías de estilo). |
| `content-creator` | Crea contenido de marketing optimizado para SEO con una voz de marca consistente. Incluye analizador de voz de marca y optimizador SEO. |
| `context-driven-development` | Úsalo al trabajar con la metodología de desarrollo dirigido por contexto de Conductor, gestionando artefactos de contexto del proyecto. |
| `copy-editing` | Edita, revisa o mejora textos de marketing existentes. Úsalo cuando el usuario pide revisión o feedback de sus textos. |
| `copywriting` | Redacta, reescribe o mejora textos de marketing para cualquier página (inicio, landing, precios, producto). Enfocado en conversión y persuasión. |
| `deep-research` | Ejecuta investigación autónoma de múltiples pasos usando el Agente de Investigación Profunda de Google Gemini. Para análisis de mercado, revisiones de literatura, etc. |
| `defi-protocol-templates` | Implementa protocolos DeFi con plantillas listas para producción (staking, AMMs, gobernanza, préstamos). |
| `employment-contract-templates` | Crea contratos de empleo, cartas de oferta y documentos de políticas de RRHH siguiendo mejores prácticas legales. |
| `framework-migration-legacy-modernize` | Orquesta la modernización de sistemas legados usando el patrón "strangler fig", permitiendo el reemplazo gradual de componentes obsoletos. |
| `free-tool-strategy` | Planifica, evalúa o construye herramientas gratuitas con fines de marketing (generación de leads, SEO, conciencia de marca). |
| `hr-pro` | Socio de RRHH profesional y ético para contratación, onboarding, gestión de permisos, rendimiento y relaciones con empleados. |
| `market-sizing-analysis` | Calcula el tamaño del mercado (TAM, SAM, SOM) y la oportunidad de mercado cuando el usuario lo solicita. |
| `marketing-ideas` | Proporciona estrategias de marketing probadas e ideas de crecimiento para productos SaaS, priorizadas por viabilidad. |
| `marketing-psychology` | Aplica ciencia del comportamiento y modelos mentales a decisiones de marketing, priorizadas por impacto psicológico y viabilidad. |
| `notion-template-business` | Experto en construir y vender plantillas de Notion como un negocio de productos digitales sostenible. |
| `page-cro` | Analiza y optimiza páginas individuales para mejorar el rendimiento de conversión (CRO). |
| `paywall-upgrade-cro` | Crea u optimiza paywalls, pantallas de actualización (upgrade) y flujos de venta cruzada (upsell) en aplicaciones. |
| `pricing-strategy` | Diseña estrategias de precios, empaquetado y monetización basadas en valor y disposición a pagar del cliente. |
| `sales-automator` | Redacta correos fríos, seguimientos y plantillas de propuestas. Crea páginas de precios y guiones de ventas. |
| `screenshots` | Genera capturas de pantalla de marketing de tu aplicación usando Playwright para Product Hunt, redes sociales, etc. |
| `scroll-experience` | Experto en construir experiencias inmersivas basadas en scroll (paralaje, narración interactiva, web cinemática). |
| `seo-cannibalization-detector` | Analiza múltiples páginas para identificar superposición de palabras clave y problemas de canibalización SEO. |
| `seo-content-auditor` | Analiza contenido para calidad, señales E-E-A-T y mejores prácticas SEO. Ofrece puntuación y recomendaciones. |
| `seo-content-planner` | Crea esquemas de contenido completos y grupos de temas (topic clusters) para SEO. Planifica calendarios de contenido. |
| `seo-content-refresher` | Identifica elementos obsoletos en contenido y sugiere actualizaciones para mantener la frescura (estadísticas, fechas). |
| `seo-content-writer` | Escribe contenido optimizado para SEO basado en palabras clave y briefs. Crea contenido atractivo y completo. |
| `seo-fundamentals` | Principios fundamentales de SEO incluyendo E-E-A-T, Core Web Vitals y calidad de contenido. Herramienta educativa. |
| `seo-keyword-strategist` | Analiza el uso de palabras clave, calcula densidad y sugiere variaciones semánticas y palabras clave LSI. Evita sobre-optimización. |
| `seo-meta-optimizer` | Crea títulos meta y descripciones optimizados, y sugerencias de URL basadas en límites de caracteres y mejores prácticas. |
| `seo-snippet-hunter` | Formatea contenido para ser elegible para fragmentos destacados (featured snippets) y características SERP. |
| `seo-structure-architect` | Analiza y optimiza la estructura del contenido (jerarquía de encabezados), schema markup y enlazado interno. |
| `startup-business-analyst-business-case` | Genera documentos de caso de negocio completos listos para inversores con mercado, solución, finanzas y estrategia. |
| `startup-business-analyst-financial-projections` | Crea modelos financieros detallados a 3-5 años con ingresos, costos, flujo de caja y escenarios. |
| `startup-business-analyst-market-opportunity` | Genera análisis completos de oportunidad de mercado con cálculos TAM/SAM/SOM. |
| `startup-financial-modeling` | Construye proyecciones financieras, modelos de ingresos y cálculos de burn rate para startups. |
| `team-composition-analysis` | Planifica la estructura del equipo, determina necesidades de contratación y diseña organigramas y planes de compensación. |
