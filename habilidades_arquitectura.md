# Habilidades de Arquitectura

Este documento lista las habilidades de la categoría "Architecture" con una breve descripción de su función en español.

| Habilidad | Descripción |
| --- | --- |
| `architect-review` | Arquitecto de software experto especializado en patrones de arquitectura moderna, arquitectura limpia, microservicios, sistemas orientados a eventos y DDD. Revisa diseños de sistemas. |
| `architecture` | Marco de toma de decisiones arquitectónicas. Análisis de requisitos, evaluación de compromiso (trade-offs), documentación ADR. Úsalo al tomar decisiones de arquitectura o analizar sistemas. |
| `architecture-decision-records` | Escribe y mantiene Registros de Decisiones de Arquitectura (ADRs) siguiendo mejores prácticas para la documentación de decisiones técnicas. Úsalo para documentar decisiones técnicas significativas. |
| `automate-whatsapp` | Construye automatizaciones de WhatsApp con flujos de trabajo de Kapso: configura disparadores de WhatsApp, edita gráficos de flujo de trabajo, gestiona ejecuciones, despliega funciones y usa bases de datos. |
| `avalonia-viewmodels-zafiro` | Patrones óptimos de creación de ViewModel y Wizard para Avalonia usando Zafiro y ReactiveUI. |
| `bash-linux` | Patrones de terminal Bash/Linux. Comandos críticos, tuberías (piping), manejo de errores, scripting. Úsalo cuando trabajes en sistemas macOS o Linux. |
| `binary-analysis-patterns` | Domina patrones de análisis binario incluyendo desensamblado, descompilación, análisis de flujo de control y reconocimiento de patrones de código. Úsalo al analizar ejecutables. |
| `brainstorming` | Usa esta habilidad antes de cualquier trabajo creativo o constructivo (características, componentes, arquitectura, cambios de comportamiento o funcionalidad). Transforma ideas vagas en planes concretos. |
| `browser-extension-builder` | Experto en construir extensiones de navegador que resuelven problemas reales - Chrome, Firefox y extensiones multi-navegador. Cubre arquitectura de extensiones, manifest v3, etc. |
| `c4-architecture-c4-architecture` | Genera documentación completa de arquitectura C4 para un repositorio/base de código existente usando un enfoque de análisis ascendente (bottom-up). |
| `c4-code` | Especialista experto en documentación nivel Código C4. Analiza directorios de código para crear documentación completa a nivel de código C4 incluyendo firmas de funciones, argumentos, dependencias, etc. |
| `c4-component` | Especialista experto en documentación nivel Componente C4. Sintetiza documentación nivel Código C4 en arquitectura nivel Componente, definiendo límites de componentes, interfaces y relaciones. |
| `c4-context` | Especialista experto en documentación nivel Contexto C4. Crea diagramas de contexto del sistema de alto nivel, documenta personas, viajes de usuario (user journeys), características del sistema y relaciones externas. |
| `code-refactoring-refactor-clean` | Experto en refactorización de código especializado en principios de código limpio, patrones de diseño SOLID y mejores prácticas de ingeniería de software moderna. Analiza y mejora el código. |
| `codebase-cleanup-refactor-clean` | Experto en refactorización de código especializado en principios de código limpio, patrones de diseño SOLID y mejores prácticas de ingeniería de software moderna (Similar al anterior). |
| `competitor-alternatives` | Cuando el usuario quiere crear comparaciones de competidores o páginas alternativas para SEO y habilitación de ventas. También para páginas de "alternativa a" o "vs". |
| `context-degradation` | Reconoce patrones de fallo de contexto: pérdida en el medio, envenenamiento, distracción y conflicto. |
| `core-components` | Biblioteca de componentes centrales y patrones de sistema de diseño. Úsalo al construir interfaces de usuario (UI), usar tokens de diseño o trabajar con la biblioteca de componentes. |
| `cpp-pro` | Escribe código C++ idiomático con características modernas, RAII, punteros inteligentes y algoritmos STL. Maneja plantillas, semántica de movimiento y optimización de rendimiento. |
| `cqrs-implementation` | Implementa Segregación de Responsabilidad de Comando y Consulta (CQRS) para arquitecturas escalables. Úsalo al separar modelos de lectura y escritura u optimizar el rendimiento de consultas. |
| `ddd-context-mapping` | Mapea relaciones entre contextos acotados (bounded contexts) y define contratos de integración usando patrones de Context Mapping de DDD. |
| `ddd-strategic-design` | Diseña artefactos estratégicos de DDD incluyendo subdominios, contextos acotados y lenguaje ubicuo para dominios de negocio complejos. |
| `ddd-tactical-patterns` | Aplica patrones tácticos de DDD en código usando entidades, objetos de valor, agregados, repositorios y eventos de dominio con invariantes explícitas. |
| `domain-driven-design` | Planifica y dirige trabajo de Domain-Driven Design desde el modelado estratégico hasta la implementación táctica y patrones de arquitectura orientada a eventos. |
| `doc-coauthoring` | Guía a los usuarios a través de un flujo de trabajo estructurado para la co-autoría de documentación. Úsalo cuando el usuario quiera escribir documentación, propuestas o especificaciones técnicas. |
| `docs-architect` | Crea documentación técnica completa a partir de bases de código existentes. Analiza arquitectura, patrones de diseño y detalles de implementación para producir documentación detallada. |
| `elixir-pro` | Escribe código Elixir idiomático con patrones OTP, árboles de supervisión y Phoenix LiveView. Domina concurrencia, tolerancia a fallos y sistemas distribuidos. |
| `email-systems` | Sistemas de email para marketing y notificaciones. Enfocado en el ROI, personalización y evitar el envío masivo sin estrategia. |
| `error-detective` | Busca en logs y bases de código patrones de error, trazas de pila y anomalías. Correlaciona errores a través de sistemas e identifica causas raíz de manera proactiva. |
| `error-handling-patterns` | Domina patrones de manejo de errores en varios lenguajes incluyendo excepciones, tipos Result, propagación de errores y degradación elegante para construir aplicaciones resilientes. |
| `event-sourcing-architect` | Experto en event sourcing, CQRS y patrones de arquitectura orientada a eventos. Domina diseño de almacenes de eventos, construcción de proyecciones, orquestación de sagas, etc. |
| `event-store-design` | Diseña e implementa almacenes de eventos (event stores) para sistemas basados en eventos. Úsalo al construir infraestructura de event sourcing o elegir tecnologías de almacenamiento. |
| `godot-gdscript-patterns` | Domina patrones de Godot 4 GDScript incluyendo señales, escenas, máquinas de estado y optimización. Úsalo al construir juegos en Godot o implementar sistemas de juego. |
| `haskell-pro` | Ingeniero experto en Haskell especializado en sistemas de tipos avanzados, diseño funcional puro y software de alta fiabilidad. Úsalo proactivamente para programación a nivel de tipos. |
| `i18n-localization` | Patrones de internacionalización y localización. Detección de cadenas hardcodeadas, gestión de traducciones, archivos locales, soporte RTL. |
| `inngest` | Experto en Inngest para trabajos en segundo plano serverless-first, flujos de trabajo orientados a eventos y ejecución duradera sin gestionar colas o workers. |
| `julia-pro` | Domina Julia 1.10+ con características modernas, optimización de rendimiento, despacho múltiple y prácticas listas para producción. Experto en el ecosistema Julia. |
| `minecraft-bukkit-pro` | Domina el desarrollo de plugins de servidor Minecraft con APIs Bukkit, Spigot y Paper. Especializado en arquitectura orientada a eventos, sistemas de comandos, manipulación de mundos. |
| `monorepo-architect` | Experto en arquitectura monorepo, sistemas de construcción y gestión de dependencias a escala. Domina Nx, Turborepo, Bazel y Lerna para desarrollo eficiente multi-proyecto. |
| `multi-agent-patterns` | Domina arquitecturas multi-agente: orquestador, peer-to-peer y jerárquicas. |
| `n8n-mcp-tools-expert` | Guía experta para usar herramientas MCP de n8n eficazmente. Úsalo al buscar nodos, validar configuraciones, acceder a plantillas o gestionar flujos de trabajo en n8n. |
| `nestjs-expert` | Experto en framework Nest.js especializado en arquitectura modular, inyección de dependencias, middleware, guardias, interceptores y pruebas. |
| `nx-workspace-patterns` | Configura y optimiza espacios de trabajo monorepo Nx. Úsalo al configurar Nx, límites de proyectos, optimizar caché de construcción o implementar comandos "affected". |
| `on-call-handoff-patterns` | Domina los traspasos de turno de guardia (on-call) con transferencia de contexto, procedimientos de escalada y documentación. |
| `parallel-agents` | Patrones de orquestación multi-agente. Úsalo cuando múltiples tareas independientes pueden ejecutarse con diferente experiencia de dominio o requieren análisis exhaustivo. |
| `powershell-windows` | Patrones de PowerShell para Windows. Trampas críticas, sintaxis de operadores, manejo de errores. |
| `production-code-audit` | Escanea autónomamente bases de código completas línea por línea, entiende arquitectura y patrones, luego la transforma sistemáticamente a nivel de producción corporativa. |
| `projection-patterns` | Construye modelos de lectura y proyecciones a partir de flujos de eventos. Úsalo al implementar lados de lectura CQRS, vistas materializadas u optimizar consultas. |
| `prompt-engineering` | Guía experta en patrones de ingeniería de prompts, mejores prácticas y técnicas de optimización. Úsalo para mejorar prompts o aprender estrategias de prompting. |
| `saga-orchestration` | Implementa patrones saga para transacciones distribuidas y flujos de trabajo entre agregados. Úsalo al coordinar procesos de negocio multi-paso y compensaciones. |
| `salesforce-development` | Patrones expertos para desarrollo en plataforma Salesforce incluyendo Lightning Web Components (LWC), triggers y clases Apex, APIs REST/Bulk, etc. |
| `skill-developer` | Crea y gestiona habilidades de Claude Code siguiendo las mejores prácticas de Anthropic. Úsalo al crear nuevas habilidades o modificar skill-rules.json. |
| `software-architecture` | Guía para arquitectura de software enfocada en calidad. Úsalo al escribir código, diseñar arquitectura o analizar código. |
| `tailwind-design-system` | Construye sistemas de diseño escalables con Tailwind CSS, tokens de diseño, bibliotecas de componentes y patrones responsivos. |
| `tailwind-patterns` | Principios de Tailwind CSS v4. Configuración CSS-first, consultas de contenedor, patrones modernos, arquitectura de tokens de diseño. |
| `testing-patterns` | Patrones de prueba Jest, funciones de fábrica, estrategias de mocking y flujo de trabajo TDD. |
| `tool-design` | Construye herramientas que los agentes pueden usar eficazmente, incluyendo patrones de reducción arquitectónica. |
| `unreal-engine-cpp-pro` | Guía experta para desarrollo en Unreal Engine 5.x C++, cubriendo higiene de UObject, patrones de rendimiento y mejores prácticas. |
| `wcag-audit-patterns` | Realiza auditorías de accesibilidad WCAG 2.2 con pruebas automatizadas, verificación manual y guía de remedición. |
| `workflow-orchestration-patterns` | Diseña flujos de trabajo duraderos con Temporal para sistemas distribuidos. Cubre separación flujo/actividad, patrones saga, gestión de estado y determinismo. |
| `workflow-patterns` | Úsalo al implementar tareas según el flujo de trabajo TDD de Conductor, manejando puntos de control de fase y commits git. |
| `zapier-make-patterns` | Automatización no-code que democratiza la construcción de flujos de trabajo. Zapier y Make (antes Integromat) permiten automatizar procesos sin código. |
